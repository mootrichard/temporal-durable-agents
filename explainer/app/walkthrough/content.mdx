!owner Coordinator process

The coordinator returns two bounded assignments. The application parses that
plan before it starts each investigator.

```ts ! src/baseline/orchestrator.ts
const planTurn = await runCodex('coordinator', {
  role: 'planner',
  prompt: plannerPrompt,
  sandboxMode: 'read-only',
  outputSchema: delegationPlanJsonSchema,
});

const plan = parseDelegationPlan(JSON.parse(planTurn.finalResponse));
const sourceAssignment = assignmentFor(plan, 'source');
const testAssignment = assignmentFor(plan, 'tests');
```

```text !prompt src/codex/prompts.ts · coordinator planning prompt
You are coordinating a small TypeScript bug fix in an isolated fixture repository.

Return a delegation plan immediately with exactly two read-only investigations:
1. one focused on the implementation;
2. one focused on the test contract.

Do not inspect files, run commands, or use tools during this planning turn. The delegated investigators own that work. Do not edit files. Keep each assignment bounded and evidence-oriented.
```

## !!steps Keep each Codex thread ID

!owner Coordinator process

The Codex runner reports a thread ID after the thread starts. The process keeps
that ID so later work can resume the same thread.

```ts ! src/codex/live-runner.ts
const thread = request.threadId
  ? this.codex.resumeThread(request.threadId, threadOptions)
  : this.codex.startThread(threadOptions);

const streamed = await thread.runStreamed(request.prompt, {
  ...(request.outputSchema ? { outputSchema: request.outputSchema } : {}),
  ...(request.signal ? { signal: request.signal } : {}),
});

for await (const event of streamed.events) {
  // !focus(1:4)
  if (event.type === 'thread.started') {
    threadId = event.thread_id;
    hooks.onThread?.(threadId);
  }
}
```

## !!steps Kill the process-owned continuation

!owner Process memory

The snapshot, active joins, and thread IDs live in one process. `SIGKILL`
removes that orchestration state.

```ts ! src/supervisor/fleet-supervisor.ts
async kill(runId: string): Promise<RunSnapshot> {
  const managed = this.requireRun(runId);

  // !focus(1:3)
  terminateProcessGroup(managed.target, this.ownerToken, 'SIGKILL');
  managed.process = undefined;
  managed.target = undefined;

  managed.snapshot = {
    ...managed.snapshot,
    phase: 'interrupted',
    workersOnline: false,
  };
}
```

## !!steps Restart from the beginning

!owner API supervisor

The supervisor has no durable continuation. It creates a clean workspace and a
new initial snapshot.

```ts ! src/supervisor/fleet-supervisor.ts
async restart(runId: string): Promise<RunSnapshot> {
  const managed = this.requireRun(runId);

  // !focus(1:6)
  if (managed.mode === 'baseline') {
    managed.workspace = await createRunWorkspace(runId);
    managed.snapshot = createInitialSnapshot(
      runId, managed.mode, managed.runnerMode,
    );
  }
  this.spawnFleet(managed);
}
```
